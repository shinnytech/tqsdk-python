============================================================
在 WorkBuddy 中高效学习和使用 TqSdk
============================================================

`WorkBuddy <https://www.workbuddy.cn/>`_ 是腾讯推出的 AI 工作台，可以根据自然语言任务读取项目文件、执行操作，并交付文件和分析结果。配合 TqSdk Skills，你可以让它编写行情脚本、整理数据、解释接口或排查策略问题。

本教程使用 **WorkBuddy 桌面端的本地任务**：选好项目文件夹，把 TqSdk Skills 交给它，再提出一个具体需求。第一次可以从“导出 K 线到 CSV”开始，完成后在右侧结果区查看文件。

1. 安装 WorkBuddy，选择工作空间
============================================================

从 `WorkBuddy 官网 <https://www.workbuddy.cn/>`_ 下载适合自己系统的桌面客户端，按安装向导完成安装并登录。Windows 的具体步骤见 `官方安装指南 <https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide>`_。

新建任务时，把工作空间设为你的 TqSdk 项目文件夹。第一次使用，可以新建一个 ``tqsdk-demo`` 文件夹；已有项目则选择包含策略脚本、依赖文件和运行说明的项目根目录。后续生成的脚本、数据和报告都要求保存到这个空间。

需要分析已有脚本时，可以在对话中补充文件、报错日志和运行命令，让 WorkBuddy 基于实际项目处理。

2. 先把 TqSdk Skills 交给 WorkBuddy
============================================================

把下面的提示词复制到任务对话中。它会引导 WorkBuddy 下载完整技能包、阅读使用规则，并按任务需要准备本地环境。

.. include:: ../_includes/tqsdk_ai_agent_intro.rst
   :end-before: .. tqsdk_skills_ref_marker

希望后续任务也能选择这项技能，可以按 `WorkBuddy 官方技能说明 <https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market>`_ 导入：

1. `下载完整的 TqSdk 技能包 <skills/tqsdk-trading-and-data.zip>`_，保留 ZIP 文件。
2. 打开 WorkBuddy 的 **技能** 页面，选择 **添加技能 → 上传技能**，上传这个 ZIP 文件。
3. 在 **已安装** 中确认出现 TqSdk 技能，并保持启用；发起任务时在对话框中选择它。

如果当前客户端无法导入或下载失败，可以手动解压完整技能包到工作空间，告诉 WorkBuddy 其中 ``SKILL.md`` 的位置，并要求它先阅读，再按需读取 ``references/``。保留 ``scripts/`` 等配套目录，详细说明见 :ref:`tqsdk_skills`。

3. 检查运行代码所需的环境
============================================================

运行 TqSdk 脚本前，让 WorkBuddy 先检查项目的 Python 解释器、虚拟环境和依赖约束。**没有安装 TqSdk 时，先安装到这个项目使用的环境，验证可以导入后再继续；已有可用版本时不要自动升级。**

技能包中的 ``scripts/check_environment.py`` 可用于检查解释器、TqSdk 版本和导入路径。它只检查环境，实际安装由 WorkBuddy 按项目依赖要求执行；只询问概念或解释代码时，无需安装软件。

你可以这样补充环境要求：

.. code-block:: text

   请先检查这个项目的依赖文件和虚拟环境，确认实际使用的 Python 路径。
   如果缺少 TqSdk，按项目依赖约束安装到该环境；不要自动升级已有版本。
   验证能导入后，告诉我 Python 路径、TqSdk 版本和导入位置，再继续完成任务。

需要核对接口实现时，可让它查看当前环境中已安装的 TqSdk 源码；也可以提供 `TqSdk 源码仓库 <https://github.com/shinnytech/tqsdk-python>`_，同时说明正在使用的版本。

.. note::

   能导入 TqSdk 只表示本地依赖可用。获取在线行情还需要网络、快期账户认证和相应数据权限。账户密码在本地通过环境变量等方式配置，不要粘贴到任务对话或运行日志里。

4. 发起第一个任务
============================================================

WorkBuddy 的 `任务栏 <https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Task-Bar>`_ 提供三种工作模式，可以按任务选择：

.. list-table::
   :header-rows: 1
   :widths: 24 76

   * - 模式
     - 在 TqSdk 中怎么用
   * - 默认（Agent）
     - 编写并运行行情脚本、导出数据、修改指定文件。
   * - 计划（Plan）
     - 多文件修改或复杂研究，先查看方案，再确认执行。
   * - 仅问答（Ask）
     - 解释接口、理解已有代码，不执行任务。

任务中写清楚 **目标、数据范围、运行模式和交付文件**。下面这个例子适合使用默认（Agent）模式，在读取技能后发送：

.. code-block:: text

   请使用 TqSdk 获取螺纹钢主连 KQ.m@SHFE.rb 最近 200 根已完成的 1 分钟 K 线。
   这是只读行情任务，不下单、不连接实盘交易账户。
   在当前工作空间生成 fetch_klines.py，并把结果保存为 rb_1m.csv。
   保留时间、开高低收和成交量字段，说明时间的时区；排除尚未完成的最后一根 K 线。
   读取数据要有超时和退出条件，结束时关闭 TqApi。
   先检查环境和本地认证配置，不要在对话或日志中输出密码。
   完成后运行脚本，核对 CSV 的有效行数、首尾时间和空值情况。
   如果认证、网络或数据权限不足，请报告实际原因，不要用模拟数据补齐。

5. 查看结果，再继续修改
============================================================

按照 `官方结果查看说明 <https://www.workbuddy.cn/docs/workbuddy/Results>`_，可以在任务右侧查看产物、工作空间文件和变更：

* **产物 / 工作空间文件**：找到生成的 Python 脚本和 CSV，检查文件位置及数据内容。
* **变更**：查看修改了哪些文件，是否符合任务范围。
* **任务对话**：核对实际运行命令、执行结果、数据行数和首尾时间。语法检查通过不等于已经成功获取行情。

确认导出结果后，可以在同一任务中继续提出小范围修改，例如“读取刚才的 CSV，生成收盘价走势图，并说明时间范围”。让后续结果使用已经核对的数据，并保留脚本和运行方法，方便复现。

运行模式与交易操作
============================================================

给 WorkBuddy 说明当前是行情查询、回测、模拟还是实盘，已有项目沿用原来的账户模式。首次学习交易程序可从本地模拟开始；实盘下单、撤单和调整仓位需要明确的操作授权。提供日志时去除凭证，修改策略后按实际运行模式验证结果。

常见问题（FAQ）
============================================================

**找不到 TqSdk 技能，或没有使用它？**
   在“已安装”中检查是否已启用，在任务对话中选择技能。仍无法使用时，把解压后的完整目录放入工作空间，明确提供 ``SKILL.md`` 路径。

**只给了代码，没有运行？**
   检查是否处于“仅问答”模式。需要执行时使用默认模式，并提供项目工作空间；让 WorkBuddy 说明缺少的是执行权限、Python、依赖、认证还是数据权限。

**已经安装 TqSdk，却提示无法导入？**
   让 WorkBuddy 报告实际 Python 路径和完整导入错误。核对是否用了另一个虚拟环境，或项目内存在同名 ``tqsdk.py`` 遮蔽安装包，不要直接尝试升级。

**需要先配置连接器或 MCP 吗？**
   这篇教程通过本地 Python 运行 TqSdk，准备好技能、运行环境和所需认证即可。连接器是另一种接入方式，按对应连接器文档单独配置。
